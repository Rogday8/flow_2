# ПОЛЕ — цветочная лавка

Второй концепт сайта цветочного магазина. Vite + React 19 + TypeScript + Tailwind CSS 4 + Motion + Lenis.

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Чем отличается от Maison Pétale

Светлый «журнальный» стиль вместо тёмной оранжереи: бумажный фон, подсолнечный жёлтый, лесной
зелёный и томатный, широкий гротеск Unbounded, рукописный Caveat и цветы-наклейки с белой обводкой.

## Что на странице

- **Загрузка** — счётчик до 100, растёт стебель.
- **Первый экран** — слово «ПОЛЕ», каждая буква залита своим полем (подсолнухи, космея, маки,
  люпин), фото сдвигается за мышью. Наклейки можно таскать, за курсором распускаются цветы.
- **Свайп-букет** — колода карточек: вправо — в корзину, влево — дальше.
- **Подбор за 3 клика** — кому, настроение, бюджет → рекомендация и ещё два варианта.
- **Каталог по цвету** — солнечные, розовые, белые, огненные, микс.
- **Обратный отсчёт** до конца приёма заказов на сегодня (21:00).
- **Сезонный круг** — диск с месяцами крутится мышкой или пальцем, в центре — что цветёт.
- **Уход** — пока листаете советы, растёт стебель и распускается подсолнух.
- **Стол с фотками** — полароиды на столе, стол таскается во все стороны.
- **Отзывы-стикеры** — их можно переставлять.
- **Корзина-чек** с оторванным краем и оформлением заказа.

Корзина хранится в localStorage. Формы заказа и подписки демонстрационные — никуда не отправляются.
Адрес, телефон и отзывы — заглушки.
